# Scoiatael (Android)

Android APK of the Scoia'tael player. The app lives in `www/index.html`; GitHub Actions wraps it with Capacitor and builds the APK.

Download: **Actions** tab → latest run → **Scoiatael-APK** (zip containing `app-debug.apk`).
To update the app, replace `www/index.html` and commit.
